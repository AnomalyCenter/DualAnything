# DualAnything

A Straftat mod that lets you dual wield any weapons.
Also adds a changeable custom keybind so you could perform alternate attacks/ADS whilst holding 2 weapons.

Obviously not vanilla compatible.

# Disclaimer
This was made 99% by chatgpt, if it wasnt clear from the code. If you want to, you can remake this mod without ai and i'll remove my mod in favor of yours.


# Installation

The intended way is to just use r2modman or another mod manager. If you want to do so manually, there's plenty of tutorials on the internet that tell you how to.
